What are Mixins?

Mixins are a powerful bytecode manipulation framework used in Minecraft modding. They allow mod developers to inject code into existing Minecraft classes without modifying the original source code. This enables mods to add features, fix bugs, or change behavior while maintaining compatibility.

How This Works

This site tracks which repositories are most frequently referenced in mixin configurations across GitHub. Higher reference counts indicate repos that are commonly targeted by other mods for integration, compatibility, or extension purposes.
